Phase 1Subnetting Calculation
Given Information
📍Base Network Address:  192.168.1.0
🏢Number of Departments (Subnets):  3
Step 1 — Find Number of Borrowed Bits

We need at least 3 subnets. Using the formula 2ⁿ ≥ number of subnets needed, we test values of n until we find enough subnets. With n=1 we only get 2 (not enough), so we try n=2 which gives 4 — enough for 3 departments.

Formula: 2ⁿ ≥ Number of Subnets
         2¹ = 2 → Too few ✗
         2² = 4 → Enough ✅
Therefore: n = 2 bits borrowed
Step 2 — Calculate New Subnet Mask (Binary)

Starting from a normal Class C address (all zeros in the 4th octet), we borrow 2 bits from the left of the host portion. Those 2 bits become "1"s, changing octet 4 from 0 to 192.

Normal Class C before borrowing:

Octet 111111111= 255
Octet 211111111= 255
Octet 311111111= 255
Octet 400000000= 0

After borrowing 2 bits:

Octet 411000000= 192← 2 borrowed bits here
New Subnet Mask = 255.255.255.192 (/26)
Block Size = 64
Step 3 — Convert Last Octet Binary to Decimal

Verify the binary-to-decimal conversion. The two borrowed bits correspond to positions 2⁷ (128) and 2⁶ (64). Adding these gives 192.

Bit Position76543210
Binary11000000
2⁷ = 128
2⁶ = 64
128 + 64 = 192 ✅
Step 4 — Calculate All Three Subnets

With a block size of 64, subnets jump by 64 each time: starting at 0 → 64 → 128. Each subnet contains 64 addresses (62 usable hosts + network ID + broadcast).

Phase 3Configure VLANs on Switch

VLANs logically separate each department's traffic on the same physical switch. Ports are assigned to VLANs in access mode (one VLAN per port for end devices). The uplink port to the router is set to trunk mode to carry all VLAN traffic simultaneously.

VLAN 10Admin/IT — Ports Fa 0/2–4

Assign switch ports Fa0/2 through Fa0/4 to VLAN 10 for the Admin/IT department. These ports connect to the Admin access point and wired Admin devices.

Switch CLI — VLAN 10 (Admin)
enable
config t
interface range fa 0/2-4
switchport mode access
switchport access vlan 10
exit
VLAN 20Finance/HR — Ports Fa 0/5–7

Assign switch ports Fa0/5 through Fa0/7 to VLAN 20 for the Finance/HR department. These ports connect to the Finance access point and wired Finance devices.

Switch CLI — VLAN 20 (Finance)
interface range fa 0/5-7
switchport mode access
switchport access vlan 20
exit
VLAN 30Customer Service — Ports Fa 0/8–10

Assign switch ports Fa0/8 through Fa0/10 to VLAN 30 for the Customer Service/Reception department.

Switch CLI — VLAN 30 (Customer Service)
interface range fa 0/8-10
switchport mode access
switchport access vlan 30
exit
Set Trunk Port (Switch → Router)

Port Fa0/1 connects the switch to the router. It must be set to trunk mode so it can carry tagged traffic from all three VLANs simultaneously — this is essential for Router-on-a-Stick inter-VLAN routing to work.

Switch CLI — Trunk Port (Fa0/1)
interface fa 0/1
switchport mode trunk
exit
do wr
Verify VLAN Configuration
Switch CLI — Verification
do show startup-config

Phase 5Configure Router (Router-on-a-Stick)

Router-on-a-Stick uses sub-interfaces on a single physical interface to route between multiple VLANs. Each sub-interface is tagged with a VLAN ID using 802.1Q encapsulation (dot1q) and assigned the gateway IP for that VLAN.

Step 1Turn Up Physical Interface

Before creating sub-interfaces, the physical GigabitEthernet 0/0 interface must be brought up with no shutdown. Note: you do not assign an IP to the physical interface — IPs go on the sub-interfaces only.

Router CLI — Enable Physical Interface
enable
config t
interface gig 0/0
no shutdown
exit
do wr
Step 2Sub-interface for VLAN 10 — Admin

Create sub-interface gig 0/0.10 for VLAN 10. The encapsulation dot1q 10 command tells the router to tag traffic with VLAN 10. Assign the Admin gateway IP 192.168.1.1 here.

Router CLI — Sub-interface VLAN 10 (Admin)
interface gig 0/0.10
encapsulation dot1q 10
ip address 192.168.1.1 255.255.255.192
exit
Step 3Sub-interface for VLAN 20 — Finance

Create sub-interface gig 0/0.20 for VLAN 20. Tag with VLAN 20 using dot1q and assign the Finance gateway IP 192.168.1.65 — the first valid host in the second subnet block.

Router CLI — Sub-interface VLAN 20 (Finance)
interface gig 0/0.20
encapsulation dot1q 20
ip address 192.168.1.65 255.255.255.192
exit
Step 4Sub-interface for VLAN 30 — Customer Service

Create sub-interface gig 0/0.30 for VLAN 30. Assign the Customer Service gateway IP 192.168.1.129 — the first valid host in the third subnet block.

Router CLI — Sub-interface VLAN 30 (Customer Service)
interface gig 0/0.30
encapsulation dot1q 30
ip address 192.168.1.129 255.255.255.192
exit
do wr
VerifyVerify Sub-interfaces

Confirm all three sub-interfaces are correctly configured with the right encapsulation and IP addresses.

Router CLI — Verification
do show startup-config
✅ You should see three sub-interfaces (gig 0/0.10, gig 0/0.20, gig 0/0.30) each with their correct dot1q VLAN tag and IP address.
Phase 6Configure DHCP Server on Router

The router acts as the DHCP server for all three departments. Each department gets its own DHCP pool with the correct network, default gateway, DNS server, and domain name. Devices will automatically receive IPs when set to DHCP mode.

EnableEnable DHCP Service
Router CLI — Enable DHCP
service dhcp
Pool 1Admin Department DHCP Pool (VLAN 10)

Create the DHCP pool for the Admin/IT department. The network and mask define the range of addresses to hand out. The default-router sets the gateway that clients receive, and dns-server points to the sub-interface for DNS resolution.

Router CLI — Admin DHCP Pool
ip dhcp pool Admin-Pool
 network 192.168.1.0 255.255.255.192
 default-router 192.168.1.1
 dns-server 192.168.1.1
 domain-name admin.com
exit
Pool 2Finance Department DHCP Pool (VLAN 20)

Create the DHCP pool for Finance/HR. The network starts at 192.168.1.64 — the second subnet block. The default router is the Finance sub-interface IP at 192.168.1.65.

Router CLI — Finance DHCP Pool
ip dhcp pool Finance-Pool
 network 192.168.1.64 255.255.255.192
 default-router 192.168.1.65
 dns-server 192.168.1.65
 domain-name finance.com
exit
Pool 3Customer Service DHCP Pool (VLAN 30)

Create the DHCP pool for Customer Service/Reception. The network starts at 192.168.1.128 — the third subnet block. The default router is the CS sub-interface IP at 192.168.1.129.
