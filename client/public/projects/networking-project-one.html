Phase 1Subnetting Calculation
Given Information
📍Base Network Address:  192.168.40.0
🏢Number of Departments:  2
🔢Number of Subnets Needed:  2
Step 1 — Find Number of Borrowed Bits

To determine how many bits to borrow from the host portion, use the formula 2ⁿ ≥ number of subnets needed. We need 2 subnets, so we solve for n.

Formula: 2ⁿ = Number of Subnets
         2ⁿ = 2
         n  = 1
Therefore: 1 bit is borrowed
Step 2 — Calculate Subnet Mask (Binary)

With 1 borrowed bit, the 4th octet's most significant bit becomes a "1", changing it from 0 (which would be /24) to 128, giving us the /25 subnet mask. The block size equals 128.

Octet 111111111= 255
Octet 211111111= 255
Octet 311111111= 255
Octet 410000000= 128← 1 borrowed bit here
Subnet Mask = 255.255.255.128 (/25)
Block Size = 128
Step 3 — Calculate Both Subnets

With a block size of 128, the first subnet starts at 0 and ends at 127 (128 addresses). The second subnet starts at 128 and ends at 255 (128 addresses).

Subnet 1 — Accounts Department
Network ID192.168.40.0
Valid Range192.168.40.1 — .126
Broadcast ID192.168.40.127
Subnet Mask255.255.255.128
Subnet 2 — Delivery Department
Network ID192.168.40.128
Valid Range192.168.40.129 — .254
Broadcast ID192.168.40.255
Subnet Mask255.255.255.128
⚠️ Block size rule: 0 → 127 = 128 addresses, then 128 → 255 = 128 addresses

Phase 4Configure Router Interfaces
Step 1Turn Up Both Interfaces

By default, all router interfaces are administratively shut down. Before assigning IP addresses, enable both GigabitEthernet interfaces simultaneously using the interface range command. The no shutdown command brings the interfaces up, and do wr saves the configuration to NVRAM.

Router CLI
enable
config t
interface range gig 0/0 - 1
no shutdown
do wr
Step 2Assign IP to Gig 0/0 — Accounts Side

Configure GigabitEthernet 0/0 with the Accounts subnet gateway IP (192.168.40.1). This interface physically connects to the Accounts switch and becomes the default gateway for all devices in the Accounts subnet. The no shutdown ensures the interface stays active after IP assignment.

Router CLI — Accounts Interface (Gig 0/0)
enable
config t
interface gig 0/0
ip address 192.168.40.1 255.255.255.128
no shutdown
exit
do wr
Step 3Assign IP to Gig 0/1 — Delivery Side

Configure GigabitEthernet 0/1 with the Delivery subnet gateway IP (192.168.40.129). This interface connects to the Delivery switch and acts as the default gateway for all Delivery department devices. Note: .129 is the first usable host address in the second subnet block (128–255).

Router CLI — Delivery Interface (Gig 0/1)
enable
config t
interface gig 0/1
ip address 192.168.40.129 255.255.255.128
no shutdown
exit
do wr
Step 4Verify Router Configuration

After saving, confirm that both interfaces are configured correctly. Run do show startup-config and look for both GigabitEthernet interfaces showing their assigned IP addresses and subnet masks. If correct, you'll see the following output:

Router CLI — Verification
do show startup-config

Expected output confirming correct configuration:

Expected Output
interface GigabitEthernet0/0
 ip address 192.168.40.1 255.255.255.128

interface GigabitEthernet0/1

Phase 5Configure Host Devices (Static IP)

Each PC and printer must be manually assigned a static IP address within its department's subnet range. Unlike DHCP, static addressing ensures each device always has the same IP — important for servers, printers, and network equipment.

How to configure each PC in Packet Tracer:  Click PC → Desktop → IP Configuration → Select Static

Phase 6Test Communication

After all devices are configured, run the following ping tests from PC1's Command Prompt to verify that both same-department and cross-department communication is working correctly through the router.

Test 1 — Same Department Communication

Verify communication between two PCs within the same Accounts subnet. This tests that the switch and IP configuration on both PCs are correct.

📍 Click PC1 → Desktop → Command Prompt

ping 192.168.40.3
✅ Expected: Reply successful
Test 2 — Cross Department Communication

Verify the router correctly routes traffic between the Accounts and Delivery subnets. This confirms the default gateways and router interfaces are properly configured.

📍 Click PC1 → Desktop → Command Prompt

ping 192.168.40.130
✅ Expected: Reply successful

Verify that an Accounts PC can reach the Delivery department's printer. Confirms end-to-end cross-subnet connectivity for non-PC devices.
