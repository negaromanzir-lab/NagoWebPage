Design and Implementation of a Hotel System Network (Vic Modern Hotel)

A complete multi-floor hotel network using 3 routers, serial DCE links, OSPF routing, VLANs per department, DHCP servers, SSH, Port Security, and wireless access — fully tested and working.

Floor 1 — Reception, Store, Logistics (VLANs 80,70,60)
Floor 2 — Finance, HR, Sales (VLANs 50,40,30)
Floor 3 — IT, Admin (VLANs 10,20)
Case StudyProject #3 Requirements

As part of your end year networking project, you are required to design and implement the Vic Modern Hotel network. The hotel has three floors with multiple departments per floor, all connected via routers placed in the server room in the IT department.

  • 🔀

    Three routers (2911) connecting each floor — all placed in the server room in IT department.

  • 🔌

    All routers connected to each other using serial DCE cable.

  • 🌐

    Network between routers: 10.10.10.0/30, 10.10.10.4/30 and 10.10.10.8/30.

  • 🔗

    Each floor has one switch placed in the respective floor.

  • 📶

    Each floor has WiFi networks connected to laptops and phones.

  • 🖨️

    Each department has a printer.

  • 🏷️

    Each department in a different VLAN with specific networks assigned.

  • 📡

    OSPF as the routing protocol to advertise routes.

  • 🤖

    All devices obtain IP addresses dynamically via DHCP — router acts as DHCP server.

  • 🔒

    SSH configured on all routers for remote login.

  • 🛡️

    Port Security on IT switch — Test-PC on fa0/1 only (sticky MAC, shutdown violation).

Phase 9Configure Port Security on IT Department Switch
Floor 3 Switchfa0/2 — Test-PC Port Security (Sticky MAC)

Only Test-PC is allowed on port fa0/2. The switch learns the MAC address automatically (sticky) and shuts down the port if any other device connects.

Floor3-SW — Port Security
enable
config t
interface fa 0/2
switchport mode access
switchport access vlan 10
switchport port-security
switchport port-security maximum 1
switchport port-security mac-address sticky
switchport port-security violation shutdown
exit
do wr
